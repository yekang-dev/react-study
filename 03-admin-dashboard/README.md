# 관리자 대시보드 (React Router 라우팅 연습)

React Router 라우팅 연습을 위한 관리자 대시보드 웹
React Router를 활용한 라우팅 구조 학습

## 사용 기술

- React Router
- JavaScript

> 스타일(CSS)은 학습 범위가 아니므로 AI 구현본의 것을 그대로 사용함.
