# React Todo List (직접 구현)

React 기초 학습을 위해 직접 작성한 Todo List 앱

## 사용 기술
- React
- Vite

## 주요 기능
- 할 일 추가
- 할 일 삭제
- 할 일 완료 처리

## 실행 방법
\`\`\`bash
npm install
npm run dev
\`\`\`
