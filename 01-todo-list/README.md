### Vue 경험이 도움이 된 부분

- 이전 Vue를 사용해봐서 컴포넌트로 화면을 나누는 것은 익숙했으나, 알던 구조를 다른 문법으로 옮기는 느낌에 가까웠음.

### 비교하며 확인한 것

**컴포넌트 분리**

- 처음엔 App.jsx에 전부 작업을 진행하였고, 컴포넌트 분리 예시 샘플에서 목록의 `<li>` 부분만 TodoItem.jsx로 빼는 것만 진행함. 이때 `<ul>`까지 같이 옮겨야 하지 않나 싶었지만 확신이 없어 그대로 진행함.

- 바이브코딩 결과에는 TodoList.jsx가 따로 있었고, `<ul>`을 담은 채 그 안에서 TodoItem을 불러오는 구조. "목록"과 "항목"으로 한 층을 더 나누어 진행하여 부족하다고 느꼈던 판단이 맞았음을 확인함.

**localStorage 분리**

- App.jsx 컴포넌트 안에서 localStorage를 직접 호출했는데, 바이브코딩 쪽은 storage.js를 따로 두고 컴포넌트에서는 함수만 호출. DB와 연결을 할 때, 코드를 로직과 분리하는 것과 같이 localStorage도 분리하여 진행하는 것을 배움.

**문법**

- 순수 JavaScript가 오랜만이라 화살표 함수 형태가 어색했고 Vue에서는 화면(.vue)과 로직(.js)을 파일로 나눠 썼는데 JSX는 한 파일에 같이 있는 것에 익숙해지는데 시간이 걸림.
